# LLM steps are single, schema-bound calls through a plain OpenAI-compatible client: no agent framework, no agent loop, no RAG

Every LLM step is exactly one request and one reply. The five steps are Insight extraction, Research Tilt proposal, Recommendation narrative, priority narrative and the Assistant's Answer, each with one versioned prompt. A step builds one `LlmRequest` (task, prompt version, system text, user prompt, JSON schema of the reply) and calls `LlmClient.complete` once. The live adapter is a thin `httpx` client that posts one OpenAI chat-completions request with `response_format: json_schema`. It offers the model no tools and makes no retry or follow-up call. The step validates the parsed reply against its Pydantic model, and any failure (transport, unparseable reply, schema mismatch) takes the existing "AI step failed" path rather than another attempt. Nothing is retrieved by similarity. Insight extraction sends every page of the Report, labelled by page number. A Research Tilt prompt carries the approved Insights, selected by a plain database query on review status, together with the engine's exposure figures. The narrative and Assistant prompts carry engine figures and a server-built Screen Context. The engine still owns every number and suitability outcome (ADR-0001). The LLM's single reply is interpreted, bounded and grounding-checked by deterministic code.

## Considered Options

- **LangChain / LangGraph orchestration**: rejected. A framework puts prompt assembly, parsing and retries behind its own abstractions, so what actually crossed the wire is no longer one object the platform owns. Capture (ADR-0004) would have to hook into framework callbacks and trust them to be complete. The steps are fixed and linear, so a graph runtime would add dependencies and upgrade churn without adding any capability they use.
- **Tool-calling agent loops**: rejected. A loop makes the number of model calls, and what the model can read, depend on the model's own choices. One step would then produce a variable chain of Exchanges, and the Audit Event would have to describe a trajectory rather than a result. Every tool becomes an authorization surface the model steers. ADR-0001 also requires that the engine, not the model, decides which figures exist.
- **Retrieval over a vector store (RAG)**: rejected. Reports in this platform fit in a single prompt, and the Insights a Research Tilt may use are defined by Insight Review status, not by similarity. Similarity retrieval would make prompt content depend on an embedding model and an index. Neither is versioned in the recording key, and both are hard to show to an Auditor. A passage could also be retrieved without the human approval that ADR-0001's grounding rule relies on.

## Consequences

One call produces one LLM Exchange, and the step's one Audit Event references it by id and hash (ADR-0004). An Auditor can therefore read the whole of what the model saw and said for any outcome without rebuilding a trajectory. Replay is deterministic: a recording is keyed by a hash of task, prompt version, system text, schema and user prompt, so recorded mode returns the same reply for the same input, and a changed prompt misses rather than replaying stale content. Live calls are as deterministic as the provider allows, and every reply is still validated and grounding-checked. The attack surface is small. The model has no tools, cannot fetch or write anything, and its reply is data checked against a schema, never an instruction the platform executes. The client depends only on the OpenAI-compatible protocol, so OpenRouter, Anthropic's compatibility endpoint or a LiteLLM gateway is a configuration change. The cost is that a step cannot reason in several passes, look things up mid-answer or recover by retrying. A Report too large for one prompt, a step that needs self-correction, or an Assistant that gathers its own context would each need a new ADR. That ADR would have to say how a multi-call trajectory is captured and anchored in the chain. Such a capability is a future deliberate decision, not a drift.
