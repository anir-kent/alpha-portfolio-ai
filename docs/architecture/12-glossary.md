# 12. Glossary

The domain vocabulary is defined once, in [`GLOSSARY.md`](../../GLOSSARY.md) at the repository root. This section links to it and does not copy it, so there is one definition per term. A capitalised domain term anywhere in this document, such as Analysis Run, Grounding or LLM Exchange, has the meaning given there. Most terms also list the words to avoid in their place.

| Terms for | Where they are defined |
| --- | --- |
| Client, Portfolio, Holding, Instrument, Asset Class, Risk Profile and Restriction | [Clients and holdings](../../GLOSSARY.md#clients-and-holdings) |
| Target Allocation, Asset-Class Drift, Tolerance Band and Portfolio Drift | [Drift](../../GLOSSARY.md#drift) |
| Analysis Run and Run Step | [Analysis](../../GLOSSARY.md#analysis) |
| Report, Insight, Insight Review and Research Tilt | [Research](../../GLOSSARY.md#research) |
| Recommendation, Trade Line, Suitability Rule, Suitability Exception, Decision and Audit Event | [Recommendation and decision](../../GLOSSARY.md#recommendation-and-decision) |
| Claim and Grounded | [Grounding](../../GLOSSARY.md#grounding) |
| LLM Exchange | [Transparency](../../GLOSSARY.md#transparency) |
| Assistant, Conversation, Question, Answer, Screen Context, Suggested Question and Out-of-Scope Refusal | [Assistant](../../GLOSSARY.md#assistant) |

Technical terms that are not domain terms keep their usual meaning: C4 container and component, Server-Sent Events (SSE), schema-bound call, recorded and live LLM modes. [8. Crosscutting Concepts](08-crosscutting-concepts.md) explains how this platform uses them.
