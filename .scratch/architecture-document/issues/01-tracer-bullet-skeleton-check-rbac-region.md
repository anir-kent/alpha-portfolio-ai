# 01: Tracer bullet: document skeleton, check command and the generated RBAC matrix

**What to build:** A reader can open the architecture folder and find an index with the document-control block plus one stub file per arc42 section (01–12), Executive Summary, Roadmap and Appendices, each with its required headings. An engineer can run one document build command in `check` mode and get a precise pass/fail: it reports missing section files or required headings, broken relative links/anchors (ADRs, glossary terms, specs), Mermaid blocks that fail to render (mermaid-cli via `npx`), and stale code-derived regions. `regenerate` rewrites marked regions in place. The first region is the RBAC role × permission matrix, generated by importing the role-permission matrix (never parsing source). CI runs `check`, so a PR that changes the matrix without regenerating the document goes red.
