# 02: ADR-0007 (single-call LLM steps) and ADR-0008 (one process on SQLite)

**What to build:** Two ADRs in the existing `docs/adr/` format that a reviewer can read cold. ADR-0007: LLM steps are single, schema-bound calls through a plain OpenAI-compatible HTTP client: no agent framework, no agent loop, no RAG. Alternatives: LangChain/LangGraph orchestration, tool-calling agent loops, vector-store retrieval. Chosen for auditability (one call → one LLM Exchange → one Audit Event), determinism under replay, small attack surface; consequence: richer multi-step reasoning is a future deliberate decision. ADR-0008: one API process on one SQLite file with hand-written idempotent migrations instead of PostgreSQL + Alembic. Chosen for zero-ops demo and the atomic scoring transaction; consequence: the single-process assumptions (ADR-0005 Run Step registry, serialised audit writes) that the Roadmap lifts.
